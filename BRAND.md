# NewsTech Identity

NewsTech is the private technology-news intelligence bot used by the **Juraa Tech Newsroom**.

## Locked naming

- Product name: **NewsTech**
- Repository/package: **NewsTechBot / newstechbot**
- Workspace label: **Juraa Tech Newsroom**
- Footer signature: **JURAA TECH • NEWS INTELLIGENCE**

User-facing Discord messages should not use the MonitoRSS name. MonitoRSS attribution belongs only in the repository attribution/license files.

## Locked palette

- Juraa Orange: `#FF6A00`
- Near Black: `#111315`
- Off White: `#F7F7F5`
- Muted Gray: `#9CA3AF`

Discord embeds use Juraa Orange as the primary accent. The other colors are documented for future dashboard/UI work.

## Voice

NewsTech should feel:
- concise
- technical
- useful
- calm
- non-clickbait

It should prioritize stories that can become useful Juraa Tech content, not maximize feed volume.

## Control Dashboard application

The Dashboard must use the Juraa palette as a controlled system:

- Dark is the dominant shell/background.
- Off White is the primary readable text.
- Orange is reserved for active states, primary actions, priority, and NewsTech recognition.
- Gray is secondary metadata and structure.
- Avoid gradients except subtle non-essential atmospheric treatment.
- Avoid cyberpunk/neon visual language.
- Keep screens simple enough to understand immediately.

The bundled NewsTech mark is a practical default/fallback. When the approved final channel logo is available, upload it through the Dashboard Brand page rather than changing identity logic throughout the codebase.
